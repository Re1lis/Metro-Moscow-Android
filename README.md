# Метро Москвы — Android

Нативное Android-приложение для тех, кто хочет исследовать Московский метрополитен, отмечать посещённые станции и сохранять впечатления от поездок.

> Проект создаётся при участии искусственного интеллекта OpenAI Codex. ИИ помогает с проектированием интерфейса, написанием и проверкой кода; направление разработки и продуктовые решения задаёт автор проекта.

## Возможности

- 16 линий и 273 станции Московского метро;
- отметки посещённых станций, дат поездок и личных заметок;
- быстрый свайп карточки станции для моментальной смены статуса посещения (`SwipeToDismissBox`);
- **Интерактивная геолокация**: поиск ближайшей станции с анимацией сканирования (минимум 5 секунд) и надёжным определением координат через все доступные провайдеры;
- **История поездок**: отдельная вкладка с хронологическим дневником всех посещённых станций;
- **Шеринг прогресса**: генерация карточки статистики для соцсетей и мессенджеров;
- анимированный стартовый экран (Splash Screen с пружинной анимацией);
- поиск и фильтры по статусу и избранному с индикатором загрузки;
- общий прогресс и статистика по каждой линии;
- улучшенный высококонтрастный Glance-виджет для главного экрана с процентами;
- еженедельные push-уведомления с напоминанием о прогрессе;
- система достижений;
- справочник по шести сериям поездов с фотогалереями;
- системная, светлая и тёмная темы, а также выбор акцентного цвета;
- экспорт и импорт резервной копии прогресса;
- полностью автономная работа без сервера и API.

## Технологии

- Kotlin;
- Jetpack Compose и Material 3;
- Jetpack Glance (виджеты для главного экрана);
- WorkManager (фоновые напоминания);
- Android Gradle Plugin 9.4;
- Gradle 9.6;
- локальное хранение данных на устройстве (`SharedPreferences`).

Минимальная версия: Android 8.0 (API 26). Целевая версия: Android 17 (API 37).

## Запуск

1. Откройте папку проекта в Android Studio.
2. Дождитесь завершения Gradle Sync.
3. Выберите эмулятор или подключённое Android-устройство.
4. Запустите конфигурацию `app`.

Сборка из командной строки:

```powershell
.\gradlew.bat assembleDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Структура

- `MainActivity.kt` — экраны, анимированный сплеш-скрин, поиск, списки станций, история и навигация;
- `MetroViewModel.kt` — состояние приложения и бизнес-логика;
- `data/MetroSeed.kt` — линии, станции и географические координаты;
- `data/MetroRepository.kt` — сохранение, импорт и экспорт прогресса и настроек;
- `data/TrainSeed.kt` — описания и изображения поездов метро;
- `ui/theme/Theme.kt` — темы оформления и акцентные цвета;
- `widget/MetroWidget.kt` — виджет прогресса для главного экрана;
- `worker/ReminderWorker.kt` — еженедельные push-уведомления через WorkManager.

## Статус

Проект находится в активной разработке. Текущая версия — `0.4.0`.

Приложение является независимым проектом и не связано с ГУП «Московский метрополитен».
