# Метро Москвы — Android

Нативное Android-приложение для тех, кто хочет исследовать Московский метрополитен, отмечать посещённые станции и сохранять впечатления от поездок.

> Проект создаётся при участии искусственного интеллекта OpenAI Codex. ИИ помогает с проектированием интерфейса, написанием и проверкой кода; направление разработки и продуктовые решения задаёт автор проекта.

## Возможности

- 16 линий и 273 станции Московского метро;
- отметки посещённых станций и даты поездок;
- личные заметки и избранные станции;
- поиск и фильтры;
- общий прогресс и статистика по каждой линии;
- достижения;
- справочник по шести сериям поездов с фотогалереями;
- системная, светлая и тёмная темы;
- пять акцентных цветов;
- экспорт и импорт резервной копии прогресса;
- полностью автономная работа без сервера и API.

В Android-версию сознательно не включены ИИ-чат и раздел истории метро из раннего iOS-прототипа.

## Технологии

- Kotlin;
- Jetpack Compose и Material 3;
- Android Gradle Plugin 9.4;
- Gradle 9.6;
- локальное хранение данных на устройстве.

Минимальная версия: Android 8.0 (API 26). Целевая версия: Android 17 (API 37).

## Запуск

1. Откройте папку проекта в Android Studio.
2. Дождитесь завершения Gradle Sync.
3. Выберите эмулятор или подключённое Android-устройство.
4. Запустите конфигурацию `app`.

Сборка из командной строки:

```powershell
.\gradlew.bat assembleDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Структура

- `MainActivity.kt` — экраны и навигация приложения;
- `MetroViewModel.kt` — состояние и действия пользователя;
- `data/MetroSeed.kt` — линии и станции;
- `data/MetroRepository.kt` — сохранение, импорт и экспорт прогресса;
- `data/TrainSeed.kt` — описания и изображения поездов;
- `ui/theme/Theme.kt` — светлая и тёмная темы.

## Статус

Проект находится в активной разработке. Текущая версия — `0.1.0`.

Приложение является независимым проектом и не связано с ГУП «Московский метрополитен».
